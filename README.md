### DAY 14 — LAB 14: Short Summary

*Main aim:* Create and present a complete *Generative AI workflow for an aviation-management problem*.

*Basically, you have to:*

1. *Choose an aviation problem* — flight disruption, complaints, passenger campaign, policy assistant, passenger experience, or responsible AI training.
2. *Make a business brief* — problem, audience, objective, outputs, privacy and compliance.
3. *Design the AI workflow* —
   *Input → AI Tool → Generation → Human Review → Verification → Approval → Final Use*
4. *Select suitable AI tools* — ChatGPT, Gemini, Canva, Gamma, image generator, document-grounded AI, GitHub.
5. *Create at least 5 prompts* and show how you improved them.
6. *Generate actual outputs* — professional writing + visual/design output.
7. *Check everything* for:

   * Hallucinations
   * Accuracy
   * Privacy
   * Compliance
   * Sources
   * Human review
8. *Create an 8–12 slide presentation* explaining the project.
9. *Prepare a GitHub portfolio* with prompts, outputs, verification, reflection, presentation and sources.
10. *Present for 7–10 minutes* and participate in peer review.
11. *Write individual reflection* answering the 10 questions.
12. *Submit GitHub link + final PDF/presentation + portfolio evidence.*

### In one line:

*Day 14 = Choose aviation problem → plan AI workflow → use multiple AI tools → create outputs → verify/correct them → make presentation → upload complete portfolio to GitHub.*# DAY-14
